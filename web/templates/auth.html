Вход с двумя факторами

Панель доступна только главному аккаунту семьи. Для первого входа отправьте боту /panel с этого аккаунта и откройте личную ссылку настройки. Остальные участники пользуются ботом для своих расходов.

Код из приложения меняется каждые 30 секунд и используется один раз. Пароль без кода не даёт доступа. Если только что использовали код, дождитесь следующего.

Настройка аутентификатора

Добавьте эту учётную запись в приложение-аутентификатор: отсканируйте QR-код или введите ключ вручную. Сохраните ключ только у себя.

15–256 символов. Используйте уникальный пароль из менеджера паролей.

Сохраните резервные коды

Каждый код можно использовать один раз вместо кода аутентификатора вместе с паролем. Сохраните их в менеджере паролей отдельно от телефона. После закрытия страницы этот список больше не показывается.
